Live GitHub
🔐 Zero-Knowledge 👨‍👩‍👧 Two-Key Inheritance 🔍 Client-Side Search ☁ Zero Cloud Storage ⏱ 2-Second Reveal 🛡️ Full Threat Model
  • AES-256-GCM encryption in browser via WebCrypto API; PBKDF2-SHA256 at 600k iterations per NIST SP 800-132 guidance; AES key created with extractable: false so it cannot be read back into JS by code, extensions, or DevTools
  • Both entry labels and values encrypted; server stores user ID, entry ID, and ciphertext blobs only; full DB compromise exposes nothing readable
  • Client-side search: all labels decrypted into browser memory on login; search filters locally; no query ever leaves the browser
  • 2-second reveal: sensitive fields decrypted on click, shown for 2 seconds, then DOM cleared and source ArrayBuffer zeroed with Uint8Array.fill(0)
  • Nominee inheritance: two-key gate (6-word diceware passphrase shared out-of-band plus server secret released after inactivity threshold plus 72h grace); owner login during grace auto-cancels; 30-day cooldown on attempts
  • Password change is atomic re-encryption: browser decrypts all entries with old key, re-encrypts with new key, submits in a single DB transaction; all-or-nothing
  • Threat model covers: DB compromise, XSS, session hijacking, username enumeration (HMAC-derived fake salt), rate limiting (5 attempts/15 min/IP), Shadow DOM wrapping password input with randomised name/id per page load
  • Self-hosted on BeagleBone AI-64; single Python process (FastAPI + APScheduler + SQLite WAL); weekly encrypted backup to Google Drive
